================================================================================
FILE DESCRIPTIONS
================================================================================

1. app.py (Main Application)
   - Entry point for the Streamlit application
   - Contains the complete UI implementation
   - Handles chat interface and message processing
   - Manages session state for chat history
   - Implements custom CSS styling for modern dark theme
   - Features:
     * Patient profile sidebar
     * Real-time chat interface
     * Patient dashboard with medical info
     * Typing indicator animation
     * Custom send button with JavaScript integration
     * Medical disclaimer notice

2. config.py (Configuration)
   - Centralized configuration management
   - Contains:
     * APP_CONFIG: Page settings (title, icon, layout)
     * THEME: Color scheme variables
     * MODEL_CONFIG: AI model settings
     * DEFAULT_USER_PROFILE: User data template

3. components.py (UI Components)
   - Modular UI component functions
   - Functions:
     * render_sidebar(): User profile form
     * render_chat_interface(): Chat input area
     * render_chat_history(): Message display
   - Note: Currently not actively used in app.py (standalone implementation)

4. utils.py (Utility Functions)
   - Helper functions for the application
   - Functions:
     * sanitize_message(): HTML escaping and formatting
     * generate_healthcare_prompt(): AI prompt generation
     * get_ai_response(): AI model interaction
     * format_chat_message(): Message HTML formatting
     * validate_user_profile(): Input validation
   - Note: Some functions defined but not actively used in current app.py

HOW TO RUN THE APPLICATION
================================================================================

Prerequisites:
1. Python 3.x installed
2. Ollama installed and running
3. Required Python packages installed

Step-by-Step Instructions:

1. Install Dependencies:
   pip install streamlit langchain-ollama

2. Start Ollama Server:
   ollama serve

3. Pull Required Model:
   ollama pull gpt-oss:120b-cloud

4. Run the Application:
   streamlit run app.py

5. Access the Application:
   - Local URL: http://localhost:8501
   - Network URL: http://[your-ip]:8501

Alternative Run Command (Headless):
   streamlit run app.py --server.headless true

================================================================================
SESSION STATE MANAGEMENT
================================================================================

Session Variables:
- chat_history: List of message dictionaries
  * Structure: {"role": "user/assistant", "content": "message text"}
  * Initialized with welcome message from assistant
  
- user_input: Current text input value
  * Cleared after processing
  
- generating_response: Boolean flag
  * True: Shows typing indicator
  * False: Normal state

================================================================================
KNOWN LIMITATIONS & CONSIDERATIONS
================================================================================

1. Ollama Dependency:
   - Requires Ollama server running on localhost:11434
   - Model must be pre-downloaded (gpt-oss:120b-cloud)
   - No fallback if Ollama is unavailable

2. Session-Based Storage:
   - Chat history lost on page refresh
   - No user authentication or multi-user support
   - No persistent patient records

3. UI Limitations:
   - JavaScript send button may not work in all browsers
   - Custom styling may conflict with Streamlit updates
   - Mobile responsiveness not fully optimized

4. AI Response Quality:
   - Depends on Ollama model capabilities
   - No fact-checking or medical validation
   - Responses are AI-generated, not verified medical advice

5. Error Handling:
   - Basic try-catch for AI generation
   - Limited error messages for debugging
   - No retry mechanism for failed requests

================================================================================
TROUBLESHOOTING
================================================================================

Common Issues:

1. "Error generating response":
   - Check if Ollama server is running (ollama serve)
   - Verify model is downloaded (ollama list)
   - Check network connectivity to localhost:11434

2. Logo not displaying:
   - Ensure logo.png exists in root directory
   - Check file permissions
   - Verify image format is valid PNG

3. Styling issues:
   - Clear browser cache
   - Check for Streamlit version compatibility
   - Disable browser extensions that modify CSS

4. Chat history not persisting:
   - This is expected behavior (session-based)
   - Use browser back button carefully
   - Avoid page refreshes

5. Send button not working:
   - JavaScript may be disabled in browser
   - Use Enter key as alternative
   - Check browser console for errors
